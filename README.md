# Soulance OS

Сборки приложения. Исходники — в приватном репозитории.

## Установка

**macOS**

```
brew tap Andrew-Jahn/tap
brew install --cask --no-quarantine soulance-os
```

**Linux** — скачай `.AppImage` из последнего релиза, сделай исполняемым, запусти.

**Windows** — скачай `.exe` из последнего релиза. При первом запуске SmartScreen попросит подтверждение: «Подробнее» → «Выполнить в любом случае».
